Asheron's Call · private server

Joining Project ACX

Two downloads and about fifteen minutes. You don't need to have played Asheron's Call before, and you don't need to sign up anywhere: your account is made the first time you log in.

What you need

  • A Windows PC with a graphics card from the last several years. Linux works too. There is no Mac version.
  • About 3 GB of free space.

Setting up

  1. Install AC:Unreal, the game

    1. Go to thwargle.com/unreal. Under Windows, click the Installer download (a file named like AC-Unreal-Setup-v159.exe).
    2. If your browser warns that the file isn't commonly downloaded, keep it anyway. In Edge: click the … next to the file, then Keep, then Show more, then Keep anyway. In Chrome: click Keep.
    3. When it's done, click the file in your browser's download list to run it.
    4. If a blue box says Windows protected your PC, click More info, then Run anyway.
    5. Click through the installer. On the last screen, leave the boxes for the Microsoft runtimes ticked and click Finish.

    These warnings show up because the installer isn't signed by a big company; it's safe. The game updates itself from then on.

  2. Download and unzip the game files

    1. Open the game files on Mega and click Download. Don't click "Save to Mega", which wants an account. Then pick Standard download if it asks.
    2. Wait for it to finish. It's one file, ac-updates.zip, about 500 MB.
    3. Open File Explorer: hold the Windows key and press E. (Or click the yellow folder on the taskbar.)
    4. In the left column, click Downloads. Find ac-updates.zip.
    5. Right-click it and choose Extract All…
    6. A window asks where to put the files. Click in the box, delete what's there, and paste this:
      FolderC:\Games\AC-Data
    7. Click Extract. A folder opens with four files in it: client_cell_1.dat, client_local_English.dat, client_portal.dat and acclient.exe. That's right; you can close it.

    Leave that folder where it is. The game reads from it every time you play.

  3. Tell the game where the files are

    1. Open AC:Unreal: click Start and type AC, then click AC:Unreal.
    2. On the login screen, click the Game files tab.
    3. Click in the DAT folder box, delete anything in it, and paste the same folder as before: C:\Games\AC-Data
    4. Click Save location. If it asks to restart, let it.

    Linux: unzip into a folder in your home instead, and paste its full path, like /home/yourname/Games/AC-Data.

  4. Add the server

    Click Browse servers, then + Custom server, and fill it in:

    Server nameProject ACX
    Hostname or IP address46.110.144.141
    Port9000
    Server typeACE

    Click Save server.

  5. Make up a login

    Open Accounts, click New account, and type a Username and Password of your choice. Click Save account.

    Nothing to register: the server creates the account the first time you log in with it. Use a password you don't use anywhere else.

  6. Log in and play

    Pick Project ACX and your account, click Launch, make a character, then click Play.

    Your pack starts with the ACX Guide. Read it first: it explains what this server does differently.

If something goes wrong

"Game files are missing"
The game can't find the files at the path in DAT folder. Open File Explorer, paste C:\Games\AC-Data into the bar at the top and press Enter. If the three .dat files aren't there, redo step 2. If they are, paste the path into the game again and click Save location.
It won't connect
Check the server settings above: address 46.110.144.141, port 9000, type ACE. If they're right, the server may be restarting for an update; try again in a few minutes.
Wrong password
The first login made your account with the password you typed then. If you've forgotten it, ask the server's admin to reset it.
